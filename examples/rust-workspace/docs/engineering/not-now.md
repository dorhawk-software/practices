# Not now

What we decided not to do yet, and why, so we come back to it
(common/not-now.md). Done items leave the list.

- **Greetings in other languages (2026-11-11).** Hello speaks English only.
  Translating needs a message catalogue (Fluent) and a way to pick the
  language; not worth it for one sentence yet. Comes back when a second
  sentence is added.
- **Windows builds (2026-11-11).** Not built or tested. The code has nothing
  platform-specific, so it most likely works; CI would add a Windows job,
  which costs about twice a Linux minute in a private repository.
