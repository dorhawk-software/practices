# UI design

How an app's interface is designed, built and kept true to its design, in
any language or toolkit. The toolkit-specific how-to (GPUI, React Native,
the web) lives with its language, linked from these pages.

## What belongs here

A lesson about how people see and use an app, learned in a real project:
layout, platform conventions, design process, accessibility, motion,
wording on screen. Each page says what, why (the incident, linked), how
to apply it, and how to check it, like the rest of the practices.
